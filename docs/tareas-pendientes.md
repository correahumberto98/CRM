# Tareas pendientes después de publicar el CRM

## Autocompletado y validación de direcciones en Contactos

- Estado: pendiente; desarrollar después de publicar el CRM.
- Mostrar sugerencias de direcciones mientras el usuario escribe.
- Al seleccionar una sugerencia, completar Address, City, State y Zip Code.
- Evaluar el proveedor, la cobertura de países y el costo por uso. Google Places es una opción considerada, todavía sin conectar.
- Configurar las credenciales, restricciones de acceso y límites de consumo del servicio elegido.
- Evaluar validación adicional de direcciones (por ejemplo, Address Validation) para detectar direcciones incompletas o incorrectas; el autocompletado por sí solo no garantiza su validez.
- Mantener la entrada manual cuando el servicio no esté disponible o no encuentre la dirección.

Criterio de finalización: las sugerencias funcionan al crear y editar contactos, los campos seleccionados se guardan correctamente y la entrada manual sigue disponible.
